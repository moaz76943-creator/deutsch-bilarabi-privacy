Introduction

Deutsch بالعربي is an offline-first German language learning application designed for Arabic speakers. We prioritize user privacy. This policy explains how the app accesses, processes, and handles data in compliance with Google Play User Data policy, Data safety requirements, and Core App Quality guidelines.

The app is designed to function primarily without an internet connection. Most learning content, progress, and features operate entirely on your device.

Data We Access and Process

Microphone / Audio (RECORD_AUDIO)

  • Purpose: The optional pronunciation trainer feature may request microphone access to record your voice for on-device speech analysis or practice (e.g., comparing pronunciation). Permission is requested at the time of use (not at app launch), with a clear rationale shown to the user, and the feature degrades gracefully if denied.
  • Collection: Audio is processed locally on your device only. We do not transmit, store on servers, or share audio recordings. Per Google Play Data safety guidelines, pure on-device processing that never leaves the device is not considered "collection" or "sharing".
  • Data Safety: No voice data is collected or shared off the device. Declare "No" for Audio files / Voice or sound recordings in the Play Console Data safety form.
  • You can deny the permission; the feature will degrade gracefully (text-based practice remains available).

Network Access (INTERNET, ACCESS_NETWORK_STATE)

  • Purpose: Optional features such as checking for content updates, downloading additional packs (if implemented), or Play Integrity / App Integrity checks. The core app works offline.
  • Data: No personal data is required or collected via the network for core functionality. Any network requests are minimal and for app functionality only. Data in transit is encrypted (HTTPS).

Local Storage

  • Learning progress, preferences, and vocabulary data are stored locally on your device (using SharedPreferences or similar secure local storage, with encryption where sensitive).
  • We do not upload this data to any servers. Uninstalling the app deletes all local data.

No Other Sensitive Data

The app does not collect or access:

  • Location data
  • Contacts, calendar, or SMS
  • Photos or videos (storage and media permissions are explicitly removed via tools:node="remove")
  • Advertising IDs or tracking data
  • Account information (no user accounts required for core use)
  • Any personal identifiable information (PII)
  • Device identifiers beyond what is necessary for Play Integrity (and only when network is available)

Data Safety Declaration (for Google Play)

  • Data collected: None. On-device processing of optional microphone input does not leave the device and is not declared as collected data. No data is transmitted off-device for collection purposes.
  • Data shared: None.
  • Security practices: Data encrypted in transit where applicable (HTTPS); local data protected by Android sandbox and encryption where used. App uses Google Play App Signing (upload key separate) and Play Integrity API for integrity protection.
  • Users can request data deletion: Since no server-side data is stored, uninstalling the app removes all local data. No account deletion needed. Contact us for any questions.

App Integrity, Signing, and Target SDK

To meet Google Play security standards and Core App Quality guidelines:

  • The app is distributed via Google Play App Signing (upload key separate from the signing key managed by Google).
  • We use the Play Integrity API for device and app integrity checks where network is available (requires CLOUD_PROJECT_NUMBER configured for production).
  • As of August 31, 2026, new apps and updates must target Android 16 (API level 36) or higher. This app targets API 36. Existing apps must target at least API 35 to remain available to new users on newer devices.
  • allowBackup is false; cleartext traffic is disabled; data extraction rules are configured.

Children's Privacy

The app is suitable for general audiences. We do not knowingly collect data from children under 13.
